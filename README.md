# KK-RPC 框架

## 项目介绍

### 目录结构

kk-rpc/
├── example-common/
├── example-consumer/
├── example-provider/
├── example-springboot-consumer/
├── example-springboot-provider/
├── kk-rpc-core/
├── kk-rpc-easy/
├── kk-rpc-spring-boot-starter/
├── README.md
└── pom.xml

- example-common: 示例代码的公共依赖，包括接口、模型等
- example-consumer: 示例服务消费者代码
- example-provider: 示例服务提供者代码
- kk-rpc-easy: 简易版 RPC 框架
